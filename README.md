Astara Retail Peru is a company with more than 15 years of successful experience 
in the automotive market. They specialize in the sale of new and pre-owned vehicles, 
accessories, genuine parts, and after-sales service.

This project features a Home View with cards for each Showroom the client has

This project also features a New Vehicle Inventory Item to allow the client to
add a new vehicle

This project uses DDD to experience a better organization

This project also uses i18n translation aswell as pinia

To run this project you first have to do npm run install, then do cd server
json-server --watch db.json and then in another terminal do npm run dev
